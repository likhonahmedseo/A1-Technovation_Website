Activation

How to Activate A1 Mail Dynamics

The Machine ID ties each non-trial license to one specific computer or device.

Install and run the app

Download the Windows app from Google Drive, install it, and open A1 Mail Dynamics on your machine.

Create an account or log in

Set up your username, email address, name/company name, and password, or log into your existing account.

Open License Activation

Go to the License Activation screen inside the app. For paid, yearly, or lifetime licenses, copy the displayed Machine ID.

Send your details

Send your Machine ID plus your contact details to A1 Technovation. The seller generates your license key using that Machine ID.

Paste the license key

Copy the license key you receive, paste it into the activation screen, and activate the app.

Important: Non-trial licenses are machine-bound. For renewals, use the same Machine ID again. If you change machines, send the new Machine ID so a replacement license can be generated.
